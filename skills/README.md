# Skills Proyek Sistem Reservasi

Kumpulan skill lokal untuk coding agent (format standar `SKILL.md` dengan frontmatter,
kompatibel Claude Skills / dapat dibaca agent apa pun via `AGENTS.md`).

| Skill | Isi |
|---|---|
| [`project-workflow`](project-workflow/SKILL.md) | Siklus kerja end-to-end user: rencana → verifikasi → eksekusi → bukti → PR |
| [`git-conventions`](git-conventions/SKILL.md) | Branch, conventional commit, aturan verifikasi-sebelum-push, PR via gh CLI |
| [`quality-verification`](quality-verification/SKILL.md) | Gerbang kualitas: pint, test, migrate:fresh --seed, skrip bukti |
| [`environment-setup`](environment-setup/SKILL.md) | PHP/MySQL/Laravel environment + jebakan PowerShell/Windows |
