## Deployment Notes
- Host adalah **pull-only**: deploy memakai `git fetch` + `git reset --hard origin/dev` (tanpa merge → tidak ada unmerge/conflict marker), dan host **tidak pernah** menjalankan `npm install`/`npm run build`
- Frontend dibangun di dalam Docker via `docker compose run --rm frontend` (`node:22` → `npm ci && npm run build`); `node_modules` di named volume `frontend_modules`, `package-lock.json` di host tidak berubah → working tree tetap bersih untuk pull
- Build aset terverifikasi lokal: `npm run build` sukses, `php artisan view:cache` sukses
- `php artisan migrate:fresh --seed` diverifikasi pada DB sqlite (setara skema MySQL)
- Server `.env` harus berisi APP_KEY, kredensial DB (DB_ROOT_PASSWORD), dan token tunnel Cloudflare
