## Deployment Notes
- Host **pull-only**: deploy memakai `git fetch` + `git reset --hard origin/dev`; host tidak pernah menjalankan `npm install`/`npm run build`
- Frontend dibangun di container: `docker compose run --rm frontend` (`npm ci && npm run build`); `node_modules` di named volume `frontend_modules`
- Skema memakai sintaks MySQL (`MODIFY`, `CHARACTER SET`) → run tes butuh DB MySQL `reservasi_kampus_testing`; sqlite in-memory tidak didukung
- `.env` tidak di-track (sudah masuk `.gitignore`); pastikan berisi APP_KEY + kredensial DB
- Suite penuh membutuhkan ekstensi **GD** (untuk intervention/image) — gunakan PHP dengan `ext-gd` saat menjalankan `php artisan test`
