## Deployment Notes
- Host **pull-only**: deploy memakai `git fetch` + `git reset --hard origin/dev`; host tidak pernah menjalankan `npm install`/`npm run build`
- Frontend dibangun di container: `docker compose run --rm frontend` (`npm ci && npm run build`); `node_modules` di named volume `frontend_modules`
- Build lokal terverifikasi: `npm run build`, `php artisan view:cache`, `php artisan migrate:fresh --seed` (sqlite, setara skema MySQL)
- Server `.env` harus berisi APP_KEY, kredensial DB, dan token tunnel
