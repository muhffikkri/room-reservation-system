## Perubahan sejak v1.1.0

### Reservasi pengguna
- Alur end-to-end `/reservasi`: riwayat, form pengajuan baru dengan slot picker interaktif (`components/reservation/slot-picker`), detail, dan `DELETE /reservasi/{reservation}` untuk membatalkan — `ReservationController` + `StoreReservationRequest` + view `reservasi/*` — merge PR #39 → `509585a`.
- Pembatalan hanya milik sendiri, minimal 1 jam sebelum mulai slot (BR-8); 403 untuk reservasi milik orang lain — merge PR #38 → `92309b9`.
- Validasi server via 6 Rule (`SlotTimeValid`, `BookingLeadTime`, `PendingQuota`, `NoApprovedOverlap`, `FacilityBookable` — BR-1..BR-6, BR-12) terpasang pada alur pengajuan pengguna.

### Otorisasi & role
- Grup route dipisah tegas `role:pengguna` / `role:petugas` / `role:admin` (middleware `EnsureRole`); redirect dashboard per role pasca-login (`08fc860`).
- View operasional dibatasi petugas via `ReportPolicy`/`ReservationPolicy` (`14655e0`); dashboard admin dijadikan **read-only agregat** (`028d6e0`).
- Registrasi self-service di-throttle `10,1`; `identity` & `phone` wajib unik (migration `add_unique_identity_phone_to_users_table`); sesi di-invalidasi saat role/status berubah (`307ec70` via `UserObserver`).
- Merge PR #41 → `e4de698` (pack `feat/auth-admin-isolation`).

### Kelola akun admin (BR-17)
- `Admin\AdminAccountController` + `AdminAccountRequest`: admin membuat akun petugas/pengguna/admin; akun buatan admin langsung `aktif` (BR-14).
- Pulihkan akun yang ditolak (`PATCH /admin/pengguna/{user}/pulihkan`); tolak perubahan status fasilitas ketika berstatus `perbaikan` (`3349980`).

### Riwayat verifikasi akun
- Tabel `account_verification_actions` + model `AccountVerificationAction` + `AccountVerificationService` + kolom audit di `users` (migration `add_verification_audit_to_users_table`) — setiap verify/reject/pulihkan terekam — merge PR #45 → `e03df57`.

### Tampilan & branding
- Nav aktif sinkron dengan section terlihat (`10cfdf8`), layout navigasi responsif bermerek (`bea6f78`).
- Dashboard pengguna: ringkasan aktivitas (`727108b`); penyelarasan tema layar auth/laporan/reservasi/publik/petugas/admin.
- Merge PR #40 → `8c854d0`.

### Lainnya
- Docs spesifikasi disinkronkan dengan isolasi role, audit verifikasi, dan BR-17 (PR #43 → `0a2b6c8`).
- Snapshot mingguan: [snapshot-2026-09-15](../snapshots/snapshot-2026-09-15.md).
