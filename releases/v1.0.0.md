## Fitur yang Disertakan (v1.0.0)

### Publik
- Landing page `/` — katalog fasilitas (gambar/o/status), filter (kata kunci, jenis, lokasi, kapasitas), tab pratinjau ketersediaan 26 slot 07.00–20.00 (BR-1), tanpa data pemohon (BR-13), akses login/registrasi.

### Autentikasi & Akun
- Registrasi mandiri role `pengguna` (status `pending`), login dengan throttle, logout, dashboard role-aware.
- `AccountStatusGate` + `EnsureAccountActive`: login akun non-aktif ditolak; verifikasi/tolak akun oleh admin (BR-14).
- Kelola akun admin: buat petugas & pengguna langsung `aktif` (BR-15).

### Admin
- Dashboard `/admin` — ringkasan antrian reservasi, laporan, fasilitas perbaikan, akun menunggu verifikasi.
- CRUD fasilitas: tambah/edit/nonaktifkan/aktifkan + upload foto (`Admin\FacilityController` + `FacilityRequest`).

### Petugas
- Dashboard antrian + daftar reservasi dengan filter status/tanggal + detail.
- Approve/reject/cancel dengan alasan wajib; approve aman balapan (transaksi + `lockForUpdate`, bentrok → 409, BR-7); fasilitas non-aktif tak bisa di-approve (BR-12).

### Mesin Bisnis (shared)
- Aturan slot/kuota/lead-time/overlap sebagai Rule objects (BR-1..BR-7): `SlotTimeValid`, `BookingLeadTime`, `PendingQuota`, `NoApprovedOverlap`, `FacilityBookable`.
- State machine laporan + audit `report_updates` via `ReportService` (BR-10) — logika siap, pemasangan UI menunggu milestone berikutnya.
